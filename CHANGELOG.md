## [1.0.0] - 2026-11-18

First stable release. Highlights:

- Support for DCAT-AP-SE 3.0.1
- The specification bundle (bundle.json) is now the source of truth for validation, with clearer error messages including full paths
- New web UI
- Quality report for generated RDF in CLI, REST and UI
- CLI with exit codes and help menu
- Requires Java 25 (Spring Boot 4)

### Added

- Add support for DCAT-AP-SE 3.0.1 with DatasetSeries and new properties
- Add validation against the DCAT-AP-SE specification in bundle.json
- Add recommended properties from bundle cardinality
- Add quality check of generated RDF
- Add quality report to CLI, REST and UI
- Add Thymeleaf-based UI
- Add argument validation, help menu and exit codes for CLI
- Add api-info resource and Swagger UI
- Add Prometheus metrics via actuator endpoint
- Add vocabulary for dataportal resource-role
- Add release workflow
- Add renovate for dependencies and mise tools
- Add reuse, publiccode, CODEOWNERS and SECURITY.md

- Make SpecificationLoader Spring-managed
- Write warn and error logs to stderr
- Update logback config to remove deprecation warnings

- Generate THIRD-PARTY.txt from pom.xml

- Update documentation for DCAT-AP-SE 3.0.1, UI and CLI
- Update dependencies
